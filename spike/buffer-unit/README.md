# 光伏缓存堆叠单元 · 示意三维（build123d）

给「光伏缓存堆叠机」出一套能进视口的整机示意几何：机架 + 机内输送（进出料）+ 链条升降 + 30 层非接触托条 + 出口挡停。

**布置原则：进出料机构在机器内部**，整机不外伸，包络就是 1500×1400×1800mm，装线按一个工位占位。

## 跑法

```bash
/root/workspace/automation-cad-prototype/spike/sketch/.venv/bin/python spike/buffer-unit/build_buffer_unit.py
```

产物写到 `~/.config/AutomationCAD/projects/光伏缓存堆叠单元/`：`model.step`、`model.stl`、`parts/`（逐件 STL）。
再在软件里 文件菜单 →「光伏缓存堆叠单元」打开即进 3D 视口（逐件装配，不是合并网格）。

## 这次实测（2026-10-26）

- 94 件 / 94 实体 / 包络 1500×1400×1800mm / 体积 245,581,309mm³ / 质量 873.8kg
- 机内输送 8 件：皮带 1400×1100（面高 900）、2 滚筒 Ø60、两侧板、减速机 + 750W 电机 + 链罩
- 进/出料辅助 6 件：E3Z-T81 对射光电 ×2 + 支架 ×2 + 挡停气缸 + 900 宽挡板
- 堆叠本体 80 件：4 立柱、8 横梁、4 链轨、2 链条、60 托条（30 层 × 2 根托板长边）+ 托架横梁 + 驱动座
- 干涉自检：bbox 候选 119 对，实际布尔相交 **0**（`REAL_OVERLAPS 0`）

## 边界（别当真实结构图用）

- 机构示意：没有焊缝、导轨副、链轮张紧、螺栓孔系、公差
- 质量 = 体积 × 密度，且按实心建模（型材/链条/滚筒不是空腔/管件），**偏保守偏高**，不是称重值
- 皮带按 6mm 薄板示意；电机按外形圆柱示意
- 皮带 1100 宽（1200 宽板两侧各悬 50mm），托条托 y=±600 长边、不穿输送面；层位 120+40i 不落在 894~900 皮带区间
- 单件质量工程记录里没有，界面写「未称重（工程合计 X kg）」，不按体积反推单件
