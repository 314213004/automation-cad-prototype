# 光伏缓存堆叠单元 · 示意三维（build123d）

给「光伏缓存堆叠机」出一套能进视口的整机示意几何：机架 + 链条升降 + 30 层非接触托条 + 入料段 + 出料段。

## 跑法

```bash
/root/workspace/automation-cad-prototype/spike/sketch/.venv/bin/python spike/buffer-unit/build_buffer_unit.py
```

产物写到 `~/.config/AutomationCAD/projects/光伏缓存堆叠单元/`：`model.step`、`model.stl`、`parts/`（逐件 STL）。
再在软件里 文件菜单 →「光伏缓存堆叠单元」打开即进 3D 视口（逐件装配，不是合并网格）。

## 这次实测（2026-10-26）

- 168 件 / 168 实体 / 包络 3300×1750×1800mm / 体积 316,285,591mm³ / 质量 1192.8kg
- 入料段 11 件（皮带 900×1200、2 滚筒 Ø60、侧板、4 支腿、减速机 + 750W 电机、双立柱 + E3Z-T81 对射光电）
- 出料段 13 件（同上 + 挡停气缸 + 挡板 = 放行机构）
- 堆叠本体 144 件（4 立柱、8 横梁、4 链轨、2 链条、120 托条 + 底板 + 驱动座）

## 边界（别当真实结构图用）

- 机构示意：没有焊缝、导轨副、链轮张紧、螺栓孔系、公差
- 质量 = 体积 × 密度，且按实心建模（型材/链条/滚筒不是空腔/管件），**偏保守偏高**，不是称重值
- 皮带按 6mm 薄板示意；电机按外形圆柱示意
- 单件质量工程记录里没有，界面写「未称重（工程合计 X kg）」，不按体积反推单件
