## 已知问题（记录，不阻塞）

1. **运动学标注是启发式**：STEP 不含运动学，名称/型号/层级/几何只给建议，斜向运动、夹爪对侧手指与缩回位仍需人工确认。
2. **尺寸覆盖不全**：已补 342/612 实型号（55.9%，含同系列推定），其余在底板画布按「未标注尺寸」处理；清单见 [DIMS-GAPS.md](DIMS-GAPS.md)。
3. **OPC UA 仅 SecurityPolicy=None**：接真实 PLC 前必须加证书与 Basic256Sha256。
4. **安装包未签名**：Win11 SmartScreen 会拦一次。CI 仍手动触发。
5. **数据准确性**：元器件参数为公开样本汇总，定型前以铭牌/最新样本为准；价格簿 example 条目不参与计价。
6. **离线意图路由是关键词规则**：审计已轮转（5 MB × 5 份 × 90 天），CSV 只导当前列表；回执无 token 用量。
7. **真实模型拒绝/澄清类**：仓库内 6/6 已过 MT04，但仍是单模型；换措辞需重跑 `npm run eval:agent:multiturn`。
8. **时区**：成本导出文件名断言按 Asia/Shanghai，测试请用 `TZ=Asia/Shanghai npm test`。
9. **安全光栅**：已补 8 条官方来源型号与六工位 BOM 初选，安全距离仍需按 ISO 13855 现场核算。

## 整机设计向导改进（2026-10-26）

本节记录该向导实现的功能行为、版本化身份规则与当前工程边界。
- 第 4 步真实 `MachineGeometry.parts` 俯视支持选站、X/Y mm 输入与网格拖动；示意 `placements` 仍独立。
- `MachineDesign.stationIdentities` 保存不可变工位身份；`stationGeometryLayout` v2 按身份键关联偏移。改名/重排在同一身份仍可对应时保留偏移；删除或无法对应的身份只清除相应偏移，新工位按零偏移处理；候选/需求重算不按名称或序号猜测迁移。旧 v1 只记录序号/名称，无法证明实体连续性，读取时保留工程但安全清除全部旧偏移并告警。
- 偏移纳入 review 签名；坐标或映射异常 fail-closed。不改尺寸/形状/行程。空场景与概念保存规则不变。
**边界**：仍是概念占位体，AABB 非精检；型号 CAD、结构/干涉/节拍签核和 Windows 发布验收未完成。超出机架/占地需人工复核。测试与 KB 容量见 [STATUS.md](STATUS.md)，不等同生产验收。
- **概念运动包络提示**：偏移后的当前几何输入；不支持轴显式未覆盖，候选只供人工复核，不改 review 或签核。限制见 [MACHINE-DESIGN.md](MACHINE-DESIGN.md)。
