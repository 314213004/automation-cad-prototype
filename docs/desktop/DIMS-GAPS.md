# 元件库尺寸缺口与推定清单（D5-A）

统计日期：2026-10-23。范围：`packs/builtin/iec-cn/parts.json`。

执行口径采用 D5 默认方案 A：只补厂商样本/PDS 的明确尺寸，或**同系列同壳架**官方尺寸的推定；推定条目必须写 `dims.source = "同系列推定：<参照型号>"` 和 `dims.estimated: true`。查不到、口径冲突或需要跨厂商借尺寸的，一律留空。

## 结果摘要

- 总数 371，补录前 191 条有尺寸（51.5%），补录后 **244 条（65.8%）**，剩余 127 条。
- 本批补录 53 条：官方明确尺寸 37 条，同系列推定 16 条。
- 推定占本批 16/53 = 30.2%，占当前全部有尺寸条目 16/244 = 6.6%，占全库 16/371 = 4.3%。
- 原有 191 条 `w/h/d` 数值逐条比对无变化；只新增空条目的尺寸与标记。
- 新增导轨件的 `moduleWidth` 均为 9 mm 整数倍；原有面板开孔件的历史口径（如 22.3 mm）保留不改。

复现与校验：

```bash
node scripts/backfill-dims.mjs --check
node scripts/backfill-dims.mjs --markdown
node scripts/backfill-dims.mjs --apply   # 只填空，已有 dims 一律跳过，可重复执行
```

## 剩余 127 条为何留空

主要缺口集中在传感器 35、端子与辅材 14、断路器 12、PLC 9、伺服 8、安全件 7、识别与视觉 7。共同原因是缺少可核对的逐型号官方外形尺寸，且现有资料不足以确认“同系列同壳架”。

有意未采用的候选：

- `TPC7062Ti`：只找到其他厂商相近尺寸，跨厂商借尺寸不符合口径，拒绝。
- `NP2-BG21`：官方图同时给出 43/63 等不同基准的深度标注，无法稳定还原总深，拒绝猜测。
- `NH40-100-3`：样本外形约 94×123 与库内既有 `NH40-63-3` 的 104×163×86 口径冲突，未解决前不补。
- `UK-6N`：虽有同系列 `UK-5N`，但 6 mm² 壳体的宽度/进深未得到官方确认，不推定。
- 传感器中的 E2E / NBB / E3X / FU / LR / IL / FD 等：缺失型号的壳体长度、接插件或检测头差异未核实，不按同直径直接套用。
- 伺服、安全件、视觉、隔离开关、行程开关、时间继电器、浪涌保护器等：未找到可公开核对的逐型号尺寸页，继续留空。

## 数据约束

- `dims.source` 是补录条目的必填来源；`dims.estimated` 仅允许 `true`，且来源必须以“同系列推定：”开头。
- `railMount` 只写布尔值；新增导轨件的 `moduleWidth` 必须是 9 mm 的整数倍。
- `scripts/backfill-dims.mjs --apply` 只处理没有 `dims` 的 id，不覆盖任何已有数值；重复执行写入数为 0。
