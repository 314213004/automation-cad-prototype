# 价格簿录入与覆盖率

状态：2026-10-24 回填；内置价格簿 [`packs/builtin/pricebook-cn/pricebook.json`](../../packs/builtin/pricebook-cn/pricebook.json) 为 `schemaVersion: 2`。

## 1. 录入规则

每条真实价格必须同时满足：

- `model`：页面上的完整型号/订购码；与包内简写或系列名不同时，在 `note` 写明对应关系。
- `category`：元件分类，如断路器、接触器、开关电源、伺服、PLC、安全件。
- `source`：可点击打开核实的 `http(s)` 页面，不接受登录页、验证码页、图片价签或口头询价。
- `sourceType`：`official-list`、`distributor` 或 `quote`。
- `checkedAt`：核价日期，严格使用 `YYYY-MM-DD`。
- `taxIncluded`：`true` 含税、`false` 不含税、`null` 页面未标明；为 `null` 时必须有 `note` 说明。
- 顶层 `currency` 固定为 `CNY`。

禁止：同系列推算、用不同后缀/容量/线圈电压的型号套价、把搜索结果摘要价格当页面成交价、把需要登录才能看到的价格写入。查不到就留在缺价清单。

## 2. 来源类型

| `sourceType` | 含义 | 本轮使用 |
|---|---|---|
| `official-list` | 厂商官方指导价/目录价，页面公开可核实 | 0 条：本轮未找到无需登录且含公开价格的官方价目页 |
| `distributor` | 分销商/工业品商城的公开参考价 | 64 条 |
| `quote` | 询价单或供应商书面报价 | 0 条：本轮没有可归档的询价单 |

本轮 64 条中，63 条来自西域 EHSY 商品页，1 条来自供应商网。西域条目页面同时展示“西域价”和“未税价（税率 13%）”，因此记 `taxIncluded: true`；供应商网的 `PNOZ s3 750103` 页面未标明税额，记 `taxIncluded: null`。

西域在短时间高频访问时会弹出人机校验。录入与复核必须在普通浏览器完成校验后核对型号和价格；无法完成校验时按“不可核实”处理，不录入。人机校验不是登录，也不得绕过登录、权限或付费墙。

## 3. 当前覆盖率

- 真实可用条目：**64 条**；示例条目：4 条（`EXAMPLE-*`，带 `example: true`，不计入可用条数、覆盖率或成本）。
- 分类构成：断路器 10、接触器 9、开关电源 7、伺服 7、PLC 6、安全光栅/安全件 11、安全继电器 5、按钮/指示灯 6、气动/传感器 3。
- 六工位案例：BOM **12 行**，已计价 **9 行（覆盖率 75%）**，缺价 **3 行**。
- 其中价格簿直接命中 8 行；`SY5120-5LZD` 仍由 `smc-cn` 元件库参考价补齐，因此总覆盖为 9 行。
- 2026-10-24 构建结果：材料 `¥6,654`、电气 `¥12,283.91`、人工/调试 `¥15,552`、合计 `¥34,489.91`。

覆盖率按 BOM **行数**统计，同一型号出现两次（如两行 `iC65N 1P C6`）按两行计。`priceMeta.stale` 与 `priceMeta.unknownSource` 同样按行列出。

## 4. 案例缺价清单

| 型号 | 名称 | 数量 | 为什么仍未计价 |
|---|---|---:|---|
| `MS1H1-75B30CB` | 伺服电机 750 W | 6 | 公开页面只出现 `-A331Z`、`-A332Z`、`-A334Z` 等后缀变体，没有与包内基础型号完全一致且可直接核价的页面；不按后缀变体套价。 |
| `F3SG-4SRA0640-14` | 安全光栅 | 1 | 未找到公开标价页；可检索到的 `F3SG-4RA...` 是不同系列/分辨率组合，不能替代 `4SRA0640-14`。 |
| `CP1E-N40DR-A` | PLC | 1 | 曾出现的精确页面已下线；其余页面混列 `-CH` 变体、扩展模块或同系列其他 CPU，无法确认该精确型号的独立价格。 |

`SY5120-5LZD` 的案例价仍来自元件库参考价；价格簿额外录入了可核实的完整订购码 `SY5120-5LZD-01`，但两者后缀不同，未互相套用。

## 5. 过期与来源不明

- 过期：`checkedAt` 距计算基准严格超过 180 天标为过期；恰好 180 天不标。过期条目仍参与计价，但方案卡显示「过期 L 项」，报告写「价格可能过期」。
- 来源不明：`schemaVersion: 1` 旧条目缺少 `sourceType` 或 `checkedAt` 时照常可用，但 `priceMeta.unknownSource` 会列出该行，方案卡显示「来源不明 U 项」。
- 用例：案例价格全部为 `checkedAt=2026-10-24`，相对 2026-10-24 构建基准无过期、无来源不明。

## 6. 维护流程

1. 先找到可公开打开的商品页，确认页面型号、价格、税额与库存状态。
2. 把页面 URL、型号、价格、税额说明写入价格簿；型号有对应/替代关系时写入 `note`。
3. 运行 `TZ=Asia/Shanghai npm test`、`npm run build:machine-case` 与 `npm run smoke`。
4. 重新打开抽查来源链接；失效链接应删除或替换，不能保留为“历史参考价”。

价格用于方案比较与预算区间，不构成采购报价；含税状态不确定时必须在采购前复核。
